# Decisions to revisit, without blocking the first pilot

The seed makes practical provisional choices so work can begin. No response to
this document is required before literature and provenance work.

## Scientific decisions for the agents to resolve from evidence

1. **Primary product:** DRB alone for the first audit, or paired DRB/DRC cohorts?
   Start with DRB; use the feasibility evidence to decide whether the second
   release adds a substantive comparison.
2. **Population:** a historically defined short-period giant cohort or a broader
   release cohort? Use metadata completeness and the scientific question, not
   observed forecast failures, to choose.
3. **Uncertainty:** enough full covariance/posterior information for Track A?
   If not, define sensitivity tiers or propose Track B transparently.
4. **Final validation era:** which period remains genuinely uninspected and
   supplies enough independent systems? Record every already-inspected outcome.
5. **Novelty:** which one extension changes what an astronomer can infer or do?
