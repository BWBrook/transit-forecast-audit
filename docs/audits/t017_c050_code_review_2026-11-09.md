# T017 source-level review of C050

Codex (GPT-6.1-sol), 9 November 2026. This is a code/evidence critique of
Claude's `scripts/independent_timing_check.py`, separate from the new T017
empirical-trapezoid implementation and from the parent's direct arithmetic
check of C050's saved rows.

## What is independent

Claude's script does not import the project's timing, acceptance or scoring
modules. It finds phase with a broad Astropy BLS search, assigns planets by
period, detrends independently and fits batman models. The issued forecast
epoch is used only after fitting, for comparison. This is useful independent
light-curve analysis; it is not an independent aperture extraction. PDCSAP and
SAP originate from the same SPOC observations, and both routes use the same
FITS time axis and target source data.

The b/c/d pattern and agreement with the frozen b times therefore support
robustness to analysis implementation and flux reduction. An on-time d
constrains a shared additive clock error, not every extraction/identification
artefact. Opposite residual signs and local-period shifts are consistent with
known timing variations; without a dynamical fit or measured shared temporal
variation they are not, by themselves, a uniquely identified physical mechanism
or a demonstrated dynamical anticorrelation. No pixel/centroid evidence was
supplied, and no new pixel analysis is claimed here.

## Limits to keep explicit

- The code adds a hard-coded BTJD reference. It does not itself validate all
  FITS time-system/reference headers. T017 independently validates the actual
  selected files' `TDB`, `SOLARSYSTEM` and BJD reference before using them.
- The source directory is globbed rather than bound to a predeclared file list
  and hashes. Its current saved filename list is three S105–S107 products;
  future reruns should bind that list and verify hashes before opening. This
  observation is not evidence of a protected-boundary violation in the run.
- The global planet shape is fixed in the individual timing profiles. The
  local baseline is profiled and the noise scale estimated. Those distributions
  are conditional profile-likelihood approximations, not full nuisance-marginal
  posteriors.
- Pairwise comparison uses the square root of summed reported variances even
  though the timings share photons. Its z-RMS is a descriptive agreement index,
  not an independent uncertainty-calibration or repeated-measurement test.
- Comparison is nearest-neighbour with a two-hour gate. Here the saved sequence
  is sparse enough for distinct pairing, but the code does not generally
  enforce one-to-one assignment. T017's comparison explicitly does.
- References described as NASA default rows must retain their actual source
  identity and retrieval evidence. A published linear reference does not
  reconstruct a pre-origin dynamical forecast with joint parameter uncertainty.

C050's numerical agreement is stronger evidence than the earlier same-table
arithmetic alone. It should be reported with these limits rather than the
categorical claim that it rules out every time-system or extraction artefact.
The frozen result and cohort stay unchanged.
